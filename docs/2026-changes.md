# 追加した項目

- 児発：専門的支援体制加算、関係機関連携加算の区分、家族支援加算Ⅰ・Ⅱ、子育てサポート加算。
- 保育所等訪問支援：訪問支援員特別加算Ⅰ・Ⅱ、初回加算、家族支援加算Ⅰ・Ⅱ、関係機関連携加算。
- 加算カード：確認事項、別途必要な記録、公式通知のページ、資料改正日・確認日。
- サービス別の絞り込みと旧版へのリンク。

# 確認範囲と今後の更新

事業所の加算届出・対象児童・指定権者のローカルな取扱いは未確認です。掲載項目は計画に関連する主要加算の一部であり、全加算一覧・請求判断・単位数計算ではありません。

個別の施行日を一律に2026年とする誤解を避けるため、metadata.effectiveFrom は未確定の null としています。2026-10-06 は制度内容との照合日です。適用開始日を追加する場合は改正告示・附則を個別に確認してください。

根拠：こども家庭庁「留意事項通知」令和8年3月31日改正。各カードのページはPDFの物理ページ（先頭を1）です。
