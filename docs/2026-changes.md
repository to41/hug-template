# 追加した項目

- 児発：専門的支援体制加算、関係機関連携加算の区分、家族支援加算Ⅰ・Ⅱ、子育てサポート加算。
- 放デイ：児発との共通加算9件を共用し、個別サポート加算Ⅲ、自立サポート加算、通所自立支援加算を追加。
- 保育所等訪問支援：訪問支援員特別加算Ⅰ・Ⅱ、初回加算、家族支援加算Ⅰ・Ⅱ、関係機関連携加算。
- 加算カード：確認事項、別途必要な記録、公式通知のページ、資料改正日・確認日。
- サービス別の絞り込みと旧版へのリンク。

# 放デイへの対応

| 項目 | 児発 | 放デイ |
|---|---|---|
| 専門的支援実施加算の月上限 | 12日未満は4回、12日以上は6回 | 6日未満は2回、6日以上12日未満は4回、12日以上は6回 |
| 関係機関連携加算Ⅳの文例 | 小学校・小学部等への就学時 | 企業・官公庁等への就職時。就労移行・就労継続A型/B型は対象外 |
| 不登校に関する支援 | 放デイ専用項目を表示しない | 個別サポート加算Ⅲ。学校連携・家族相談の重複算定に注意 |
| 卒業後の生活・進路 | 放デイ専用項目を表示しない | 自立サポート加算。本人・保護者の同意と自立サポート計画 |
| 自立した通所 | 放デイ専用項目を表示しない | 通所自立支援加算。安全評価・職員同行・90日間の限度 |

共通する一般支援文は共用し、園を前提とした4件は放デイ選択時だけ学校の文へ読み替えます。元の20件の一般支援文は原文のまま保持しています。サービスの切替は入力済みのワークエリアを維持します。

放デイ側の根拠は、共通加算の準用がp.53、専門的支援実施加算の上限がp.54、不登校支援がp.56～57、自立サポートがp.57～58、通所自立支援がp.58～59、関係機関連携がp.59です。共通の詳細は児発側の該当ページも併記しています。
